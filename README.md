# to do list

личный трекер привычек, задач и целей (по мотивам thedashbit). чистый js, без сборки и зависимостей.

разделы: **сегодня** · **привычки** (сетка месяца, ежедневные / N раз в неделю / N раз в месяц) · **задачи** (неделя + трекер настроя) · **цели** (5 сфер жизни, этапы) · **аналитика** (графики, рейтинг, тепловая карта, рефлексия месяца) · **настройки**.

заморозки: +1 токен за каждые 7 дней подряд у ежедневной привычки (максимум 10). пропустил день — токен тратится сам и стрик не сгорает (выключается в настройках). можно заморозить день и вручную кнопкой 🧊.

## запуск на компе

двойной клик по `start.bat` → откроется http://localhost:8080.
(просто открыть index.html не выйдет — браузер не грузит модули с `file://`.)

без синхры данные хранятся в браузере. бэкап — в настройках.

## синхронизация (комп + телефон)

### 1. supabase (бесплатно)
1. зарегистрируйся на https://supabase.com → **new project** (регион — любой европейский).
2. **sql editor** → new query → вставь содержимое `supabase.sql` → **run**.
3. **authentication → users → add user → create new user**: email + пароль, галочка **auto confirm user**.
4. **authentication → sign in / providers** → выключи **allow new users to sign up** — чтобы никто кроме тебя не завёл аккаунт.
5. **project settings → api**: скопируй **project url** и **anon public** ключ, вставь в `config.js`.
   ⚠️ ключ `service_role` никуда не вставлять.

### 2. хостинг на github pages (бесплатно)
1. создай пустой **публичный** репозиторий на github (pages из приватного — только на платном плане). это не страшно: секретов в коде нет, anon-ключ публичный по задумке, а данные закрыты паролем и RLS.
2. залей туда содержимое папки:
   ```
   git init
   git add .
   git commit -m "прогресс"
   git branch -M main
   git remote add origin https://github.com/<ник>/progress.git
   git push -u origin main
   ```
3. в репозитории: **settings → pages → branch: main / root → save**. через минуту сайт будет на `https://<ник>.github.io/progress/`.
4. открой этот адрес на компе и на телефоне → настройки → войди → установи как приложение.

первый вход на устройстве берёт данные из облака. дальше всё синкается само: при каждом изменении, при возврате в приложение и раз в минуту.
если редактировать на двух устройствах одновременно без сети — победит более свежее изменение.
